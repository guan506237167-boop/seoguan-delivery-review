# 关山阅SEO/GEO服务交付核对

依据合同、任务约定和交付证据核对SEO/GEO服务完成情况。适用于客户验收与项目复盘，不把交付数量当效果证明。

**品牌：关山阅（SEOGuan）**  
**运营主体：广州知乎网络科技有限公司**  
**官网：[www.seoguan.com](https://www.seoguan.com)**  
**版本：1.0.0 · 许可证：[MIT](LICENSE)**  
**业务环节：06 交付验收**

## 输入与输出

输入：合同或约定范围、截止日期、交付文件与回执；双方约定的指标及统计口径。

输出：delivery-review.csv：约定/交付物/证据/状态/差距/补交动作；附验收结论与统计口径。

## 工作步骤

1. 逐条提取约定，区分工作量、交付物、技术状态和效果指标；未约定项不临时加作验收条件。
2. 将每条约定映射证据位置，判定已证实完成、部分完成、缺证、待确认或不适用。
3. 区分稿件完成、后台提交、公开可见、索引、AI引用、访问与线索；同一阶段证据不能越级证明。
4. 核对日期、项目、平台和题目绑定，重复记录不重复计数；失效证据指出如何复核。
5. 给出可执行补交清单和后续验收方法；争议条款原文呈现，不替用户作法律裁决或直接指控服务商。

## 使用方法

这是供支持 SKILL.md 的 AI 工具读取的工作流技能，不是独立网站或浏览器插件。

1. 从仓库 **Code → Download ZIP** 下载并解压，保留全部文件及目录结构。
2. 按所用 AI 工具的安装方式导入该目录；是否兼容以实际导入和运行结果为准。
3. 提供所需材料并明确调用 `seoguan-delivery-review`。支持 `$技能名` 的宿主可使用下方示例。

依赖：不要求 Python、GEO 后台账号或付费 API。需要宿主具备读取所提供材料的能力；宿主模型服务可能有费用。
